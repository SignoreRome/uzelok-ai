# База знаний Uzelok

Это нейтральная база знаний, созданная сервисом Uzelok. Она не требует контракта agora,
словаря тем или Obsidian: заметки лежат обычными Markdown-файлами.

## Структура

```text
.
├── README.md
└── notes/
    └── <Тема>/
        └── <Название>.md
```

- `notes/<Тема>/` — каталог темы; имя темы получено транслитерацией свободного текста.
- `<Название>.md` — заметка. Если имя уже занято, к нему добавляется суффикс `_<job8>`.

## Поля заметки

Frontmatter каждой заметки содержит:

- `type` — `concept`, `problem` или `source_note`;
- `topic` — тема свободным текстом;
- `status` — всегда `raw`;
- `source` — `telegram`;
- `id` — UUID заметки, сгенерированный сервисом;
- `created`, `updated` — даты создания и обновления;
- `summary` — одно предложение до 150 символов.

Поля `domain` нет: оно принадлежит контракту agora и вычисляется при импорте.

## Как забрать выгрузку

Отправьте боту команду `/export` — он пришлёт zip-архив с `README.md` и каталогом `notes/`.
